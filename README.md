# 치지직 노래책 (신청곡 페이지)

치지직 스트리머의 "부를 수 있는 곡" 목록을 시청자에게 보여주고, 치지직 OAuth 로그인 후
신청곡 채팅 명령어(`!신청 곡명 - 아티스트`)를 복사해 주는 단일 페이지.

## 실행

```bash
npm install
npm run dev
# http://localhost:3000
```

`.env`가 없으면 **데모 모드**로 동작한다: "치지직으로 로그인" 클릭 시 가짜 세션(새벽감자,
DEMO 배지)이 생성돼 로그인 후 UX를 그대로 확인할 수 있다.

## 실제 치지직 OAuth 연동

1. [치지직 개발자센터](https://chzzk.gitbook.io/chzzk)에서 앱 등록, Client ID/Secret 발급.
   API Scope에 "유저 정보 조회" 포함, 리다이렉트 URI에 `http://localhost:3000/api/auth/callback` 등록.
2. `.env.example`을 `.env`로 복사하고 값 입력.
3. 서버 재시작. 이후 로그인 버튼은 실제 `chzzk.naver.com/account-interlock`으로 이동한다.

인증 흐름 (공식 문서: chzzk.gitbook.io/chzzk/chzzk-api/authorization):

```
GET  chzzk.naver.com/account-interlock?clientId&redirectUri&state   ← 로그인 화면
GET  /api/auth/callback?code&state                                  ← state 검증(CSRF)
POST openapi.chzzk.naver.com/auth/v1/token  (grantType: authorization_code)
GET  openapi.chzzk.naver.com/open/v1/users/me                       ← channelId/channelName
→ HMAC 서명된 httpOnly 쿠키 세션 발급 (만료 1일 = 액세스 토큰 수명)
```

## 곡 등록 화면 (`/admin/songs/new`)

곡 하나에 들어가는 항목: 자켓(선택) · 제목 · 가수 · MR 링크 · 키 · 장르 · 가격.

**MR 링크를 먼저 넣는 순서**로 설계했다. 유튜브 주소를 붙여넣고 `불러오기`를 누르면
oEmbed로 영상 제목·채널·썸네일을 가져와 자켓을 자동으로 채우고, 영상 제목을 쪼개
곡명/가수 후보를 추천 칩으로 띄운다. API 키도 쿼터도 필요 없다.

**여러 표기 등록.** 제목과 가수 모두 `대표 표기 + 별칭 여러 개` 구조다.
`역몽` / `사카유메` / `逆夢`을 모두 넣어두면 시청자가 어느 표기로 검색해도 걸린다.
입력값에 가나가 있으면 `lib/kana.js`가 한글 표기를 자동 추천한다
(국립국어원 외래어 표기법 기준: 어두/어중 구분, 촉음·발음 받침, 장음 생략.
ヨルシカ→요루시카, とうきょう→도쿄). 한자 읽기는 사전이 필요해 자동 변환 대상이 아니다.

**키.** −6~+6 반음을 DB에 저장한다. 유튜브 임베드는 재생 중 피치를 바꿀 수 없으므로
(cross-origin iframe이라 Web Audio가 오디오 그래프에 접근 불가, `setPlaybackRate`는
속도만 변경), 키를 0이 아닌 값으로 두면 **그 키로 올라온 MR 영상 주소**를 따로
등록하는 입력란이 열린다. 신청 시 해당 키의 영상이 재생된다.

**가격.** 곡별 신청 후원 금액. 프리셋(무료/1,000/3,000/5,000/10,000)과 직접 입력.

우측 패널에서 노래책 카드 미리보기와 "이 곡이 걸리는 검색어 목록"을 실시간으로 확인한다.

### CSV로 한번에 등록

화면 상단 `한 곡씩 입력 / CSV로 한번에` 토글로 전환한다. 스프레드시트에서 CSV로
내려받아 끌어다 놓으면 파싱 결과를 표로 보여주고, **확인한 뒤에** 등록한다.

- **인코딩 자동 감지** — UTF-8, UTF-8 BOM, EUC-KR(CP949). 한국 엑셀·한셀이 EUC-KR로
  저장하는 경우가 많아 UTF-8로 읽어 깨지면 되돌린다.
- **구분자 자동 감지** — 쉼표 / 탭 / 세미콜론.
- **RFC 4180 파싱** — 따옴표 안의 쉼표·줄바꿈, 이스케이프된 따옴표(`""`)를 처리한다.
- **열 이름 자동 매핑** — `제목·곡명·title`, `가수·아티스트·artist`, `MR링크·유튜브·url`
  같은 별칭을 인식한다. 제목·가수만 있으면 되고 나머지 열은 있으면 쓴다.
- **값 정규화** — 장르 별칭(`제이팝`→`J-POP`), 키(`원키`/`+2`/`-2`, ±6 범위로 제한),
  가격(`5,000`/`무료`), 인기곡 표시(`Y`/`O`/`1`).
- **셀 안 별칭 분리** — `;` `|` `,` 로 나누고, 슬래시는 `역몽 / 사카유메`처럼 띄어쓴
  경우만 나눈다(`AC/DC`를 쪼개지 않기 위해).
- **행별 검증** — 제목·가수가 비면 오류로 선택 불가, 이미 등록된 곡은 중복으로 표시하고
  기본 해제. 변환된 값은 경고로 남겨 무엇이 바뀌었는지 보이게 한다.
- **자켓 자동 채움** — MR 링크의 영상 ID로 썸네일 주소를 만든다(네트워크 호출 없음).
- 예시 CSV 내려받기 제공(엑셀 호환을 위해 BOM 포함). 한 번에 1,000곡까지.

## 구조

```
app/page.jsx                시청자 노래책 (그리드/리스트, 별칭 검색)
app/admin/songs/new/        곡 등록 화면
app/globals.css             디자인 시스템 (OKLCH 토큰, 다크 고정)
app/api/auth/login          OAuth 시작 (미설정 시 데모 세션)
app/api/auth/callback       code→token 교환 + users/me 조회
app/api/auth/logout         세션 삭제
app/api/me                  현재 로그인 상태 조회
app/api/songs               곡 목록 조회 / 등록
app/api/songs/bulk          CSV 일괄 등록 (최대 1,000곡, 파일 쓰기 1회)
app/api/youtube             유튜브 oEmbed 프록시 (제목·채널·썸네일)
app/api/upload              자켓 이미지 업로드 → public/uploads/
lib/chzzk.js                치지직 OpenAPI 클라이언트
lib/session.js              쿠키 세션 (HMAC-SHA256 서명)
lib/store.js                곡 저장소 (.data/songs.json, 파일 기반)
lib/kana.js                 가나 → 한글 표기 변환
lib/youtube.js              영상 ID 추출 · 제목에서 곡명/가수 후보 추출
lib/csv.js                  CSV 인코딩·구분자 감지, 파싱, 열 매핑, 값 정규화
data/songs.js               시드 노래책 데이터 + 채널 정보
data/genres.js              장르·가격 프리셋·키 표기 유틸
```

## 미검증 / 인계 사항 (블로커 아님, 정직 고지)

- **실 OAuth 왕복은 미검증** — 앱 credential이 없어 데모 모드로만 검증했다.
  `lib/chzzk.js`의 토큰/유저 응답이 `{ content: {...} }` 래핑인지 실 응답으로 확정 필요
  (`TODO(handoff)` 주석 참조).
- 토큰 갱신(`grantType: refresh_token`)은 미구현 — 세션 수명을 액세스 토큰과 동일(1일)로
  묶어 갱신 없이 재로그인하는 정책. 장기 세션이 필요하면 refresh 로직 추가.
- **`/admin` 접근 제어 없음** — 지금은 누구나 곡을 등록할 수 있다. 스트리머 본인만
  들어오게 하려면 세션의 `channelId`를 소유자 채널 ID와 대조하는 가드가 필요하다.
- **저장소가 파일 기반**(`.data/songs.json`) — 기획·데모용이다. 동시 쓰기 보호가 없고
  서버리스 환경에서는 유지되지 않으므로, 운영 전 실제 DB로 교체해야 한다.
- 곡 수정·삭제 화면 없음 (등록만 구현). 목록 관리 화면이 다음 단계.
- 신청은 "채팅 명령어 복사"까지가 범위 — 신청 목록 서버 저장/스트리머 대시보드는 다음 단계.
- 가격은 표시·명령어 생성까지만 — 실제 결제·후원 연동은 범위 밖.

## 검증 기록

- `npm run build` 통과 (라우트 10개).
- 가나→한글 변환 13케이스 통과 (`lib/kana.js`).
- 등록 화면 CDP 조작 테스트 9건 통과: 유튜브 메타 조회, 자켓 자동 채움, 제목 후보 추출,
  별칭 칩 등록, 가나→한글 추천, 검색 매칭 집계, 키 스테퍼 + 키별 MR 입력란, 미리보기 반영, 저장.
- 시청자 화면 별칭 검색 6건 통과: 역몽 / 사카유메 / 逆夢 / 米津玄師 각각 정확히 매칭,
  부분일치, 무매칭.
- CSV 불러오기 CDP 파일 업로드 테스트 21건 통과: UTF-8/EUC-KR 인코딩 감지, 구분자 감지,
  따옴표 안 쉼표, 이스케이프 따옴표, 별칭 분리, `AC/DC` 미분리, 장르·키·가격 정규화,
  키 범위 제한, 필수값 누락 차단, 중복 감지, 선택 개수 집계, 일괄 저장.
- 일괄 등록 API 가드 4건 확인: 빈 배열, 1,000곡 초과, 잘못된 행 포함, 정상 저장.
